# Machine Learning Coursework

This repository contains four machine learning homework assignments and related deliverables.

## Repository Structure

- `112550018_HW1/` — Homework 1 source code, tests, and assignment PDF
- `112550018_HW2/` — Homework 2 source code, tests, and assignment PDF
- `112550018_HW3/` — Homework 3 source code, project files, and assignment PDF
- `112550018_HW4/` — Homework 4 notebook, report files, and model weights

## Homework Focus Summary

- **HW1**: Linear Regression (closed-form and gradient descent), learning curve analysis, and linear model/regularization concepts (L1 vs L2).
- **HW2**: Binary classification with Logistic Regression and Fisher Linear Discriminant (FLD), including evaluation with accuracy and AUC.
- **HW3**: Ensemble learning and tree methods, covering AdaBoost, Bagging, and Decision Tree with feature importance and impurity metrics.
- **HW4**: Kaggle image-classification competition workflow (data processing, model design, training strategy) plus SVM theory questions.

## Notes

- Python-based assignments include a `setup.cfg` and `main.py`.
- Homework 1 and Homework 2 include test files (`test_main.py`).
